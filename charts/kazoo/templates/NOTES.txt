## 1. Set your own secrets
Every change_me_* value in secrets.* is shared across every pod -- replace
them all before this is anything more than a throwaway test install:
  --set secrets.erlangCookie=<random> --set secrets.rabbitPass=<pw> \
  --set secrets.couchPass=<pw> --set secrets.couchSecret=<pw> \
  --set secrets.postgresPass=<pw> --set secrets.masterPass=<pw>

## 2. Watch it come up
  kubectl get pods -w
The data plane (couchdb/rabbitmq/postgres) must be Ready before kazoo-apps.
kazoo-apps then runs its first-boot bootstrap (system DBs, master account,
Monster-UI app registration) -- allow a few minutes, and don't be alarmed by
a couple of CrashLoopBackOff cycles before it settles; the bootstrap is
idempotent and retries on its own.

## 3. Reach the UI / API
Both default to ClusterIP -- port-forward to reach them locally:
  kubectl port-forward svc/{{ include "kazoo.service" (dict "ctx" . "name" "monsterUi") }} 8080
  kubectl port-forward svc/{{ include "kazoo.service" (dict "ctx" . "name" "kazooCore") }} 8000
Open http://localhost:8080 and point Monster-UI at http://localhost:8000/v2.
For Monster-UI to call back into Crossbar itself, it needs a browser-reachable
Crossbar URL baked in at install time -- set that explicitly with
--set monsterUi.crossbarApiUrl=... (or enable kazooCore.httpRoute below and
it's derived automatically).

## 4. Exposing SIP to real phones
Phones must reach kamailio at exactly the address it advertises in its SIP
headers, or registration and call teardown silently fail:
  * kamailio.service.type=LoadBalancer + kamailio.advertiseIP=<LB DNS/IP>
  * freeswitch.service.type=LoadBalancer + freeswitch.service.includeRtp=true
    + freeswitch.kazooLocalAddress=<same LB DNS/IP> for the RTP media path
Both default to ClusterIP (in-cluster only) until you set these.

## 5. Optional: Gateway API HTTPRoutes
Needs the gateway.networking.k8s.io/v1 CRDs installed:
  --set kazooCore.httpRoute.enabled=true --set kazooCore.httpRoute.hostname=api.example.com \
  --set monsterUi.httpRoute.enabled=true --set monsterUi.httpRoute.hostname=ui.example.com

## 6. Known limitations
  * Single-replica only: the data plane is one-node StatefulSets, and running
    more than one FreeSWITCH/kamailio replica is untested.
  * The shared app-metadata volume needs ReadWriteMany storage (set
    shared.storageClass if your default StorageClass is RWO-only).
